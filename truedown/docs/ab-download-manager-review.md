# AB Download Manager feature review

Reviewed on 2026-09-08 against the public [AB Download Manager repository](https://github.com/amir1376/ab-download-manager), commit `c1b824d4fc679706073ba96f7500e3012a8754d5`. The repository declares Apache-2.0. This review inspected source behavior; no upstream implementation was copied into TrueDown. Priorities below are recommendations based on TrueDown's current architecture, not upstream claims.

## What this change covers

TrueDown now has eight default file groups, including engineering files, custom group names, suffix lists and output subdirectories, combined group/search/status filtering, a compact download form, and a task information/settings view. New tasks are saved beneath the selected root in their group directory; existing task views reclassify without moving files. Task status uses the list dropdown, while the sidebar holds groups and utilities.

The engineering defaults reuse TrueDown's canonical Dropbox filter suffixes. Classification preferences and Dropbox exclusion preferences remain independent: assigning a suffix to a group does not exclude a download.

## Scope choices

Existing aria2 connection, retry, speed, resume, browser-integration and native tray capabilities should be extended through the current core rather than replaced with a second download engine. AB's [DownloadSettings](https://github.com/amir1376/ab-download-manager/blob/c1b824d4fc679706073ba96f7500e3012a8754d5/downloader/core/src/commonMain/kotlin/ir/amirab/downloader/DownloadSettings.kt) provides useful product comparisons for these existing controls.

Queues/scheduling offer the largest new capability. Group subdirectories are now implemented; manual group assignment is the closest follow-up to the current organization work. Per-host policies are a smaller, practical reliability improvement. The remaining items can follow without expanding the everyday download form.
