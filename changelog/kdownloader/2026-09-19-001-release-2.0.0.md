# KDownloader 2.0.0 - TrueDown API-only HTTP service

- Align the extension release notes with the shared 2.0.0 product version and
  TrueDown's removal of its browser dashboard. TrueDown's HTTP listener now
  serves APIs only; opening its address in a browser no longer opens a dashboard.
  Use the TrueDown desktop application or CLI to manage downloads.
- KDownloader's AB-compatible integration with TrueDown remains compatible,
  including the default local endpoint `http://127.0.0.1:15151`. Keep the backend
  running; the removed browser dashboard is not required for extension downloads.
- TrueDown no longer issues or accepts browser session cookies for API access.
  If API Key authentication is enabled in TrueDown, enter its key in
  KDownloader's ABDM backend settings. KDownloader already sends the key through
  `X-Api-Key` without browser cookies and stores it only in local extension
  storage. The key remains optional when backend authentication is disabled.
- This transition does not change extension download behavior, supported sites,
  permissions, saved settings, or download history. No extension data reset or
  history migration is required.
