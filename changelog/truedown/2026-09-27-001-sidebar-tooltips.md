# Sidebar traffic and custom hover descriptions

- Show downloading and failed task counts with icons in the sidebar. Hide the
  traffic overview when no task is downloading, while preserving update notices
  and Settings navigation.
- Replace native browser title bubbles throughout the dashboard, settings,
  new-task form and task details with shared project tooltips: compact dark
  labels for short hints and theme-aware cards for longer details and errors.
- Support keyboard focus, Escape dismissal, pointer travel into the tooltip,
  viewport fitting, live descriptions and cleanup on navigation or removal.

## Verification

- Shared UI consistency and mirror checks.
- Browser acceptance for tooltips and update notices in both color schemes,
  including keyboard dismissal, live changes, narrow layouts and idle traffic.
