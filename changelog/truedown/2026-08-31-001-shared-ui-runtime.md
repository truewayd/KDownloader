# Shared UI runtime

- Connected the TrueDown dashboard to the repository's canonical component
  runtime while preserving its standalone branding, native Light DOM forms,
  current layout, and muted teal theme.
- Replaced the dashboard's local toast lifecycle and icon normalization with
  shared behavior.
- Added a generated byte-for-byte component mirror because Go cannot embed a
  parent directory, plus sync checks that fail tests and release builds when
  the mirror is stale.

## Verification

```text
npm run ui:check
npm test
cd truedown
go test ./...
go vet ./...
```
