# Keep resolved folders together

- Save expanded folders and Telegraph articles under their module by default, preserving their original hierarchy. Choose file categories in Engine and Modules to place expanded files under Pictures, Videos and other groups.
- Browse tasks by enabled resolver from the Library sidebar in module layout. Reorder modules with a drag or Alt+Up/Down.
- Use slimmer scrollbars and more room for labels in the narrow sidebar.
- Open the configured save location from the workspace toolbar or context menu using “Open download folder”.

## Verification

- Collection layout, settings compatibility, task filtering and sidebar navigation are covered by core and browser regression checks.
