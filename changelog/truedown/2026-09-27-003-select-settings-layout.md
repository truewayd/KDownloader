# TrueDown interface refinements

- Use rounded custom option lists with keyboard navigation, selected marks and disabled states while retaining native form values and automatic settings saves.
- Support the All downloads context menu without group editing.
- Reduce the collapsed sidebar to 56px, retain its toggle on narrow windows and prevent the logo from reappearing during resize.
- Add subtle shadows to the main and settings working surfaces, align outlined settings blocks and shorten redundant help text.
- Remove fixed, informational switches from experimental settings without changing their runtime restrictions.

## Verification

- Workspace, settings, context-menu and custom-select browser acceptance in light/dark themes and narrow viewports.
- JavaScript regression suite and shared UI mirror check.
