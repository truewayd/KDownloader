# TrueDown 1.6.5 - Data safety and consistent UI state

- Require an explicit boolean before changing API authentication; malformed
  settings requests leave authentication and session cookies intact.
- Reserve HTTP payloads and `.aria2` control files together, including relative
  and absolute spellings of the same output directory. Refuse overlapping
  legacy ownership before recovery or cleanup, preserving both files.
- Keep the GET deadline active with caller cancellation on HTTP and native
  transports. Application logs use the same bounded read behavior.
- Bind default values to their starting revision before asynchronous saves,
  preventing stale snapshots from overwriting concurrent settings changes.
- Restore keyboard focus when returning to an unchanged task list, including
  cached 304 responses, without letting later polls reclaim focus.

- All five browser acceptance suites: workspace, settings, task forms, file
  groups, and auxiliary UI; narrow layouts, light/dark themes, and 200% scale.
