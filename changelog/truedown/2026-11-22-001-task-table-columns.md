# Customize the task table

- Drag the right edge of a data heading to resize its column. Keyboard users can focus the separator and use the left and right arrow keys.
- Right-click a heading or press Shift+F10 to choose columns by name. A checkmark means the column is visible. Actions stays checked and pinned in the last column, with its heading above scrolling rows and columns. The menu also restores automatic widths. TrueDown remembers the layout in the current profile.
- Automatic widths fit the localized headings and sort icons. Short filenames appear in full. Longer names shorten in the middle of the basename so the extension stays readable. Selection boxes and task actions stay visible while the data columns scroll horizontally. A soft shadow appears at each pinned edge with more content in that direction.

- Windows native menu tests check the action allowlist, icons and localized labels.
