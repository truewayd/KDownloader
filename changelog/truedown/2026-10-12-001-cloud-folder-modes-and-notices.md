# TrueDown cloud folder modes, shared suffix filtering and notices

- MEGA module 0.2.0 accepts public files, folders and selected folder children. The default folder mode generates one local ZIP; expanded mode creates independent files with their relative hierarchy. aria2 owns every ciphertext transfer and resume checkpoint. The module verifies every file MAC before any ZIP or file is published.
- MEGA, Dropbox and Google Drive folder expansion share the user's Project/Custom/Off suffix filter. Native Google documents are filtered after choosing their export extension. Direct files and ZIP contents bypass the expansion filter. Legacy extension writes preserve both provider modes and an explicitly empty custom list.
- About lists dependencies and protocol/behavior references, pinned source links and original license texts. MEGAJS, SDK and MEGAcmd references are attributed accurately, including MEGAcmd's GPL portions. Native package preparation includes the locked dependency inventory. No MEGA SDK, MEGAcmd or JavaScript runtime is bundled.
- Consolidate identical update-cleanup errors into one line with a candidate count and log unchanged failures once per process. Cleanup still retries every 30 seconds and preserves changed checksums and durable receipts.
- Fix a nil-pointer panic after failed admission metadata validation. MEGA output renaming no longer compares the user's chosen name with the initial authenticated remote name; later refreshes still validate the stored remote name and size.

The full Dropbox archive was not downloaded.
- Real aria2 coordinator fixture: pause, restart after one completed and one partial member, nonzero HTTP Range, ZIP content verification, active removal and completed-output preservation. Unit tests also cover corrupt members, encrypted metadata, missing keys/parents, cycles, path collisions, shared export filtering, cleanup log suppression and metadata-rejection errors.
- Settings/About passed six browser viewport/theme combinations (1040, 820 and 390 pixels, light/dark), without overflow. Native compositor acceptance is separate.
- Full Go tests/vet, 410 Node tests (409 passed, one existing skip), 13 Python migration tests, shared UI/icons checks and a clean extension build passed. Public fixtures are supplied through environment variables; links and decryption keys are not committed. This verifies small public files and folders. Large archives, quota/hashcash, CloudRAID, account downloads, native macOS/ARM execution and published signed-module updates are not accepted by these checks. No release has been published.
