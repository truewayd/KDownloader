# Keep compact navigation aligned

- The Library scrollbar uses the sidebar's existing edge inset. Opening a group or shortening the window keeps navigation rows aligned with New download.
- Collapsed controls share the center of the rail, including the Windows titlebar toggle, category and module icons, and Settings.
- Compact reduces button, field and navigation row heights while preserving desktop sidebar widths and horizontal button padding. English settings use clearer tray and browser integration instructions, and remaining times use localized units.
- Compact navigation gives English labels and five-digit counts room on the same line. Longer status messages can wrap, and desktop settings category labels fit on one line.

## Verification

- Browser tests cover sidebar scrolling and icon alignment, English navigation and task durations, and all seven settings categories in light and dark themes.
