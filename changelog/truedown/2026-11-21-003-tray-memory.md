# Lower Windows tray memory usage

- After a window has been hidden for eight seconds, TrueDown informs WebView2 that the page is hidden and requests a smaller memory footprint. This also pauses visibility-dependent dashboard polling. Downloads and native notifications continue.
- Reopening restores the existing page and its drafts. Quick hide-and-reopen actions keep the current working set. The same policy applies when TrueDown starts in the tray.

## Verification

- An isolated Windows desktop comparison measures the private working set of the complete process tree and times foreground launches and restores.
- The native Windows smoke test checks page visibility, core availability while hidden and document identity across a tray restore.
