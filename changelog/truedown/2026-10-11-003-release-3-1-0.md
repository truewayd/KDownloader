# TrueDown 3.1.0

- Refresh untouched clipboard-filled links whenever New download is reopened, while retaining edited sources and torrent drafts.
- Extract and deduplicate links from pasted text, preserve standalone URL punctuation and modern/legacy MEGA keys, and decode modern MEGA path hash separators without changing query parameters.
- Show a separate global speed-limit entry during active downloads; open download settings from that entry without replacing the live speed display.
- Linux WebDriver editing acceptance opens keyboard menus before transferring focus to the popup. Mouse-menu behavior and native focus guards remain unchanged.
- MEGA downloading remains research-only.
