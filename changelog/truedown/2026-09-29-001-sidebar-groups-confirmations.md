# TrueDown 界面与托盘退出修复

- 修复侧栏展开、收起时导航区域可能出现横向滚动条的问题。
- 分组拖拽增加浮动预览、位置提示与边缘连续滚动，保留键盘排序及取消恢复。
- 文件分组改为独立卡片，后缀逐项输入、删除，支持批量粘贴和回车继续添加；新增分组入口置顶并保持可见。
- 自动保存保留正在编辑的后缀和空输入，继续使用原有后缀数组及修订冲突处理；清理旧编辑器样式和重复布局规则。
- 为按钮、图标按钮、开关等统一补齐指针状态，开机启动纳入设置卡片。
- 独立确认窗口按自然内容高度测量，短消息无需滚动，长消息保留细滚动条与固定操作区。Windows 使用 Mica，macOS 使用原生材质，不支持或关闭透明效果时回退实色。
- 修复 Windows 托盘菜单已确认的点击可能在菜单收起、前台窗口变化后被丢弃的问题，保留取消及内容菜单的窗口验证。

## Verification

- 浏览器验收覆盖侧栏动画、深浅色与窄窗口、拖拽与键盘排序、后缀编辑和冲突、确认窗口布局。
- Rust 单元测试、Go 测试及 vet、Node 测试、共享组件一致性检查。
- Windows 隐藏原生窗口验收通过；本机外部退出请求至桌面进程结束约 1.10 秒。引擎中断关闭约 1.00 秒，下载中安全关闭约 1.04 秒并验证续传。
- 退出计时不代表真实托盘点击耗时；托盘菜单竞态由选择状态回归测试覆盖。Mica / macOS 材质未进行可见原生窗口跨平台验收。
